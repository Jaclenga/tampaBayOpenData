# Data explorations

These R Markdown reports retrieve live public ArcGIS data through
`tampaBayOpenData`. Knit a report to rerun its analysis and generate current
tables and figures.

- [Tampa bicycle network](tampa-bicycle-network-eda.Rmd): a full-data look at
  mapped bicycle connections and reported mileage.
- [Eight short exploration stories](stories/README.md): focused examples across
  six publishers, spatial and tabular layers, and a direct ArcGIS URL.

Each report cites its source and states the limits of its analysis. The
[story guide](stories/README.md) has installation and run instructions.
