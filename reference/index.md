# Package index

## Discover

- [`list_portals()`](https://jaclenga.github.io/tampaBayOpenData/reference/list_portals.md)
  : List the configured public ArcGIS publishers
- [`list_datasets()`](https://jaclenga.github.io/tampaBayOpenData/reference/list_datasets.md)
  : List Tampa Bay ArcGIS datasets
- [`search_datasets()`](https://jaclenga.github.io/tampaBayOpenData/reference/search_datasets.md)
  : Search Tampa Bay ArcGIS datasets

## Inspect

- [`dataset_info()`](https://jaclenga.github.io/tampaBayOpenData/reference/dataset_info.md)
  : Inspect a checked or discovered dataset and its source
- [`dataset_provenance()`](https://jaclenga.github.io/tampaBayOpenData/reference/dataset_provenance.md)
  : Read the source and retrieval provenance of a result

## Retrieve

- [`get_dataset()`](https://jaclenga.github.io/tampaBayOpenData/reference/get_dataset.md)
  : Retrieve a checked or discovered ArcGIS dataset
- [`get_arcgis_layer()`](https://jaclenga.github.io/tampaBayOpenData/reference/get_arcgis_layer.md)
  : Retrieve a compatible ArcGIS layer by URL

## Download

- [`download_dataset()`](https://jaclenga.github.io/tampaBayOpenData/reference/download_dataset.md)
  : Download an ArcGIS dataset into resumable local chunks
- [`download_arcgis_layer()`](https://jaclenga.github.io/tampaBayOpenData/reference/download_arcgis_layer.md)
  : Download a direct ArcGIS layer into resumable local chunks

## Convenience functions

- [`get_permits()`](https://jaclenga.github.io/tampaBayOpenData/reference/get_permits.md)
  : Retrieve City of Tampa permit locations
- [`get_capital_projects()`](https://jaclenga.github.io/tampaBayOpenData/reference/get_capital_projects.md)
  : Retrieve City of Tampa public capital project locations
- [`get_development_cases()`](https://jaclenga.github.io/tampaBayOpenData/reference/get_development_cases.md)
  : Retrieve City of Tampa active development case locations
